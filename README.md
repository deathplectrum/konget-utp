# УТП Конгет

Приложение для проверки сайтов автодилеров, где стоит скрипт Конгет.
Работает на Windows и iPhone: это веб-приложение, которое ставится иконкой на рабочий стол или экран «Домой».

## Четыре кнопки

| Кнопка | Что делает | Когда | Где результат |
|---|---|---|---|
| 1. Проверить работоспособность сайтов | Открывает главную каждого сайта: открылась ли, код ответа, сколько секунд, не заглушка ли | По кнопке | `data/health/` |
| 2. Наличие скрипта Конгет | Ищет `app.konget.ru/inject?token=…` в коде сайта и среди загруженных файлов, ждёт отложенный скрипт | По кнопке | `data/konget/` |
| 3. Сверить УТП | Собирает цены и выгоды по сценариям и сравнивает с прошлым сбором | По кнопке и 1-го числа месяца | `data/utp/` |
| 4. Выгрузить данные в таблицу | Переписывает в Google-таблице листы «Сводка», «Работа сайтов», «Скрипт Конгет», «УТП» | По кнопке | Google-таблица |

```
Приложение (кнопка)
   │ просит GitHub запустить проверку (.github/workflows/)
   ▼
Проверка на GitHub Actions (collector/)
   │ открывает сайты из scenarios/
   ▼
data/<проверка>/latest.json + history/  ←  приложение показывает их
   │ кнопка 4
   ▼
Google-таблица
```

Статусы скрипта Конгет: «Скрипт есть» (с пометкой обычный, отложенный или через контейнер), «Токен не тот»,
«Скрипт без токена», «Проверить вручную» (скрипта не видно, но на сайте есть контейнер тегов, например Google Tag Manager,
в котором он может лежать), «Скрипта нет», «Сайт не открылся».
Если в файле сайта указан `konget_token`, проверка сверяет, что на сайте стоит именно этот токен.

Вкладки: **Главная** (4 кнопки), **УТП** (цены и выгоды), **Сайты** (работа сайта и скрипт по каждому сайту), **Настройки**.

## Ключ доступа

Кнопки работают только с ключом GitHub (инструкция на вкладке «Настройки»). Без ключа результаты можно только смотреть:
репозиторий публичный, поэтому сами результаты видны всем, у кого есть ссылка. Ключ можно выдать узкому кругу людей
и в любой момент отозвать на GitHub.

## Google-таблица

Нужен бесплатный служебный аккаунт Google: пошаговая инструкция на вкладке «Настройки».
В секретах репозитория (Settings → Secrets and variables → Actions) должны быть `GOOGLE_SERVICE_ACCOUNT` (JSON-ключ целиком)
и `SHEET_ID` (ссылка на таблицу). Таблицу нужно открыть адресу служебного аккаунта как редактору.

## Первый запуск (один раз)

1. **Включить публикацию приложения.** В репозитории: Settings → Pages → Source: **GitHub Actions**.
   Потом Actions → «Публикация приложения» → Run workflow. Через пару минут приложение откроется по адресу
   `https://deathplectrum.github.io/konget-utp/`.
2. **Создать ключ** по инструкции на вкладке «Настройки» в приложении и вставить его туда.
3. **Установить иконку.**
   - iPhone: открой адрес в Safari → «Поделиться» → «На экран Домой».
   - Windows: открой адрес в Edge или Chrome → значок «Установить приложение» в адресной строке.

## Как добавить сайт

Один сайт — один файл в папке `scenarios/`. Образец с пояснениями: `scenarios/_пример.yaml`.
Можно сначала указать только адрес страницы: сборщик сделает её снимок, и по нему подберём,
где на странице модели, цены и выгоды.

## Правила сбора

- Цена — минимальная «от» по модели, выгода — максимальная «до». Одна модель — одна строка, комплектации не учитываем.
- Если цены или выгоды нет, пишется «—».
- Цена вне 300 000 – 30 000 000 ₽ или выгода больше цены — сайт получает «Требует проверки».
- Сборщик только читает сайты: не заполняет формы и не оставляет заявок.
- История каждой проверки лежит в `data/<проверка>/history/`, записи старше 106 дней удаляются (самая свежая остаётся всегда).

## Для разработки

```
npm install
npm run dev        # приложение на компьютере
npm test           # проверки разбора цен, статусов и листов таблицы
npm run health     # кнопка 1 у себя (нужен npx playwright install chromium)
npm run konget     # кнопка 2
npm run collect    # кнопка 3
npm run export     # кнопка 4 (нужны GOOGLE_SERVICE_ACCOUNT и SHEET_ID)
```
