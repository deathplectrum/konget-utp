# УТП Конгет

Приложение собирает цены и выгоды (УТП) с сайтов автодилеров, где стоит скрипт Конгет.
Работает на Windows и iPhone: это веб-приложение, которое ставится иконкой на рабочий стол или экран «Домой».

## Как это устроено

```
Приложение (кнопка «Собрать УТП»)
   │ просит GitHub запустить сборщик
   ▼
Сборщик на GitHub Actions (collector/)
   │ открывает сайты по сценариям из scenarios/
   │ берёт модели, цены «от» и выгоды «до»
   │ сравнивает с прошлым сбором
   ▼
data/latest.json  ←  приложение показывает его на вкладках
```

- **Главная**: большая кнопка «Собрать УТП» и счётчики последнего сбора.
- **УТП**: карточки сайтов с цветными статусами. Нажми на карточку, чтобы увидеть модели и что поменялось.
- **Сайты**: список сайтов и готовность их сценариев, кнопка «Добавить сайт».
- **Настройки**: ключ GitHub, без которого кнопка сбора не работает.

Статусы: «Ошибка доступа», «Требует проверки», «Изменилось», «Первая проверка», «Не изменилось», «Нет сценария».
Сайты, которые требуют внимания, всегда сверху.

## Первый запуск (один раз)

1. **Включить публикацию приложения.** В репозитории: Settings → Pages → Source: **GitHub Actions**.
   Потом Actions → «Публикация приложения» → Run workflow. Через пару минут приложение откроется по адресу
   `https://deathplectrum.github.io/konget-utp/`.
2. **Создать ключ** по инструкции на вкладке «Настройки» в приложении и вставить его туда.
3. **Установить иконку.**
   - iPhone: открой адрес в Safari → «Поделиться» → «На экран Домой».
   - Windows: открой адрес в Edge или Chrome → значок «Установить приложение» в адресной строке.

## Как добавить сайт

Один сайт — один файл в папке `scenarios/`. Образец с пояснениями: `scenarios/_пример.yaml`.
Можно сначала указать только адрес страницы: сборщик сделает её снимок, и по нему подберём,
где на странице модели, цены и выгоды.

## Правила сбора

- Цена — минимальная «от» по модели, выгода — максимальная «до». Одна модель — одна строка, комплектации не учитываем.
- Если цены или выгоды нет, пишется «—».
- Цена вне 300 000 – 30 000 000 ₽ или выгода больше цены — сайт получает «Требует проверки».
- Сборщик только читает сайты: не заполняет формы и не оставляет заявок.
- История сборов лежит в `data/history/`, сборы старше 106 дней удаляются (самый свежий остаётся всегда).
- Сбор запускается кнопкой и сам 1-го числа каждого месяца.

## Для разработки

```
npm install
npm run dev        # приложение на компьютере
npm test           # проверки разбора цен и сравнения
npm run collect    # сбор у себя (нужен npx playwright install chromium)
```
